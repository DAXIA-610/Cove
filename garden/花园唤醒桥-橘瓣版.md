# 花园唤醒桥 · 橘瓣（RikkaHub）版

> 接口全部从 `rikkahub/rikkahub` 源码里核对过，不是猜的。

## 一、和 Operit 版的差别

| | Operit 版 | 橘瓣版 |
|---|---|---|
| 本地端口 | 8094 | 8080 |
| 投递路径 | `/api/web/chats/{对话ID}/messages/stream` | `/api/conversations/{会话ID}/messages` |
| 要不要手抄 ID | 要 | 不用，按标题自己找 |
| 鉴权 | Bearer token（必填） | 没设访问密码就完全不用 |
| 请求体 | `{message, attachment_ids, return_tool_status}` | `{parts:[{type:"text",text:"..."}]}` |
| 投递返回 | SSE 流，得等它跑完 | 202 立刻返回，模型在后台跑 |

**那个 202 不是「收到了」，是「排队了」。**

## 二、接口

| 用途 | 方法 | 路径 |
|---|---|---|
| 按标题找会话 | GET | `/api/conversations/paged?limit=100&query=<标题>` |
| 兜底全量列表 | GET | `/api/conversations` |
| 投递 | POST | `/api/conversations/{会话ID}/messages` |
| 换 JWT（设了密码才用） | POST | `/api/auth/token` |

投递请求体：

```json
{"parts": [{"type": "text", "text": "要投的内容"}]}
```

源码位置：

- `web/routes/ConversationRoutes.kt` → `post("/{id}/messages")`，内部 `sendMessage(uuid, request.parts, answer = true)`
- `web/dto/WebDto.kt` → `SendMessageRequest(val parts: List<UIMessagePart>)`
- `ai/ui/UIMessagePart.kt` → `@SerialName("text") data class Text(val text: String)`

`answer = true` 是写死的 —— 每投一条，橘瓣必然让模型跑一整轮。

## 三、装 injector

把 `garden-inject-rikka.py` 的内容**覆盖**到 `~/Cove/garden/garden-inject.py`，
桥的 `start.sh` 路径就不用动。

```bash
python3 -m py_compile ~/Cove/garden/garden-inject.py && echo "语法 OK"
```

手动喂一条：

```bash
printf '%s\n' '{"version":1,"type":"garden_wake","reason":"game_turn_required","message":"测试：轮到你了"}' \
  | python3 ~/Cove/garden/garden-inject.py
```

没有输出就是成了。

## 四、桥的配置（`~/wake-bridge/.env`）

```bash
GARDEN_BASE_URL=https://wake-v1.abysslumina.com
GARDEN_MACHINE_TOKEN=gg_xxxxxxxxxxxx
GARDEN_INJECTOR_EXECUTABLE=/data/data/com.termux/files/usr/bin/python3
GARDEN_INJECTOR_ARGS_JSON='["/data/data/com.termux/files/home/Cove/garden/garden-inject.py"]'
GARDEN_LOG_LEVEL=info

RIKKA_BASE=http://127.0.0.1:8080
RIKKA_CONV_TITLE=花园
RIKKA_ALLOW=game_turn_required
# RIKKA_PASSWORD=        # 橘瓣设了访问密码才填
```

注意：

1. `GARDEN_INJECTOR_EXECUTABLE` 要绝对路径（`which python3`）
2. `GARDEN_INJECTOR_ARGS_JSON` 外层必须单引号，不然 shell 会剥掉
3. 桥不会把 `GARDEN_MACHINE_TOKEN` 传给 injector，但其他环境变量会一起传

## 五、橘瓣特有的坑

1. **必须有个标题完全一样的会话**（严格比对，两个字就是两个字）
2. **每次唤醒都让那个会话长一条 + 烧一轮钱** —— 隔一阵清一次
3. **网页服务默认绑 0.0.0.0**（局域网可见）→ 设置里改「仅本机」
4. Termux 和橘瓣都得加电池白名单

## 六、两条铁律

- 绝不加自动重启（花园明令，修复那晚两百台机器同时连上去把服务顶了）
- 同一台机器只能有一条桥；429 就等 1-2 分钟

## 七、验收

不是看桥起来了，是看橘瓣那个会话**自己动了**。
